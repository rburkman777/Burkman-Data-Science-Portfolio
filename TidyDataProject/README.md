# 🧹 TidyDataProject
The goal of this project is to illustrate the power of data cleaning. We were able to turn what was a fairly messy, poorly organized dataset into something digestable and useable with just a few functions. 

## ✏️ Project Overview
The project aims to guide users through the process of tidying data using Python. The project uses a Markdown notebook to illustrate this to users. The app also includes several visualizations of the dataset once it has ben cleaned. 

## 📋 Project Features 
* Insturctions for users on how to use Python melt data and split columns. Also instructions on how to use Python to remove NaN values from code
* Insturctions and guide for users on how to create visualizations from data, including bar charts and pie charts
* Insturctions for users on how to create a pivot table with the data

#### How to Run the Project

Open the "TidyData_Notebook_Code.ipynb" file in VSCode and simply run each box of code. The code will output the relevant data at each step. Make sure that the olmypics_08_medalists.csv file is also open so the "TidyData_Notebook_Code.ipynb file can import it and work with it.
